# Viktor Lin - Portfolio (Next.js)

Portfolio website built with Next.js (App Router), TypeScript, and custom CSS.

## Stack

- Next.js
- React
- TypeScript
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm run start
```
